# Samuel Yeneneh Portfolio

A modern Next.js portfolio for AI, data and fintech work.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Personalize

- Replace `your@email.com` in `app/page.tsx`.
- Replace the GitHub and LinkedIn URLs.
- Add your resume as `public/resume.pdf`.
- Update project `href` values with GitHub, live demo, paper or PDF links.
- Replace the experience dates/details with the exact versions you want public.

## Deploy

Push the folder to GitHub and import the repository into Vercel. The project is already configured as a standard Next.js app.
